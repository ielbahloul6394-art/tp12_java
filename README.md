Gestion des métadonnées des fichiers

Cette partie permet de récupérer les informations d'un fichier en utilisant l'API `Files` de Java et la classe `BasicFileAttributes`.

Les informations récupérées sont :
- La taille du fichier en octets.
- La date de dernière modification.
- La vérification si le chemin représente un répertoire.
- La vérification si le chemin représente un fichier ordinaire.
